Welcome to our recipe app

You can select a recipe by selecting:
1. What meal you want (Breakfast, Lunch, and Dinner)
2. What Cuisine you want (American, Italian, Japanese, Chinese)

You are then given a list of option to chose from

It will display the ingredients, cooking time, and a basic description

There are over 100 recipes to chose form!
