What's Cookin' (A Recipe App) (Java Console)

A simple Java console application that displays region based breakfast recipes for users to prepare themselves. Recipes can be selected manually or randomly, and prepared recipes are logged for future reference.

## Features

- Two regions (e.g., North America, Asia)
- Breakfast recipes (May implement other meal types in future)
- Specific or random recipe selection
- View recipe ingredients and instructions
- Logs prepared recipes to a file
- Loads recipes from an external `recipes.txt` file

## Files

- `recipes.txt` — This stores recipe data (title, ingredients, instructions)
- `prepared_log.txt` — This logs prepared recipes with timestamps

## How to Run

1. Ensure you have Java installed.
2. Compile and run `BreakfastAppMain.java`.
3. Follow the console prompts to view and prepare recipes.
